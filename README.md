# AI 代理人系統

這是一個完整的 AI 代理人系統，包含五個核心模組：Profile（角色設定）、Memory（記憶系統）、Planning（規劃系統）、Action（動作執行）和 Map（地圖設計）。系統允許 AI 代理人在虛擬環境中行動、決策、學習和記憶。

## 系統架構

### Profile 模組 (profile.py)
- 存儲 AI 代理人的基本信息和個性特徵
- 管理狀態值如飢餓度、能量等
- 提供基於個性特徵的決策支持
- 可序列化保存/加載

### Memory 模組 (memory.py)
- 實現短期和長期記憶系統
- 提供記憶去重機制
- 支持基於相關性的記憶檢索
- 包含定期反思功能
- 可匯出記憶到 JSON 檔案查看

### Planning 模組 (planning.py)
- 管理日常時間表
- 支持短期、中期和長期目標設置
- 能將目標分解為可執行步驟
- 可動態調整計劃以應對意外事件

### Action 模組 (action.py)
- 執行各種環境交互動作
- 根據代理人狀態和計劃決定下一步行動
- 維護動作歷史記錄
- 處理動作結果和環境反饋

### Map 模組 (map.py)
- 創建 20×20 網格的虛擬環境
- 支持多種環境元素（牆壁、門、家具等）
- 提供環境描述和交互機制
- 支持代理人在環境中移動

## 使用說明

1. 安裝依賴：
   ```
   pip install numpy requests
   ```

2. 設置 DeepSeek API：
   確保 DeepSeek R1 Distill Qwen 7B GGUF 模型 API 在 http://127.0.0.1:1234 運行

3. 運行系統：
   ```
   python main.py
   ```

## 交互命令

交互式模式下可用的命令：
- `auto [steps]` - 運行指定步數的自動模擬
- `move [dir]` - 向某個方向移動 (north, south, east, west)
- `examine` - 查看當前位置周圍環境
- `interact` - 與當前單元格互動
- `plan` - 顯示當前計劃
- `status` - 顯示代理人狀態
- `map` - 顯示地圖
- `think [topic]` - 讓代理人思考一個主題
- `save` - 保存代理人狀態
- `load` - 加載代理人狀態
- `memory` - 匯出並查看記憶
- `exit` - 退出模擬

## 檔案說明

- `profile.py` - 個人資料模組
- `memory.py` - 記憶模組
- `planning.py` - 規劃模組
- `map.py` - 地圖模組
- `action.py` - 動作模組
- `ai_agent.py` - AI 代理人主類
- `main.py` - 交互式運行程序
- `memory_export.json` - 匯出的記憶檔案

## 系統特點

1. **模擬人類記憶機制**：短期和長期記憶，具有重要性評估
2. **基於個性的決策**：代理人根據其個性特徵做出不同決策
3. **複雜環境互動**：支持多種環境元素和交互方式
4. **動態計劃調整**：能夠根據環境變化調整計劃
5. **可持久化存儲**：所有模組狀態可保存和加載
6. **自我反思能力**：定期對經驗進行總結，形成更高層次理解
